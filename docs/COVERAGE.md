# Brainforge v2 requirement coverage ledger

Walks `docs/SPEC.md` section by section (line ranges refer to that file). Status was established by reading the code and the tests named here, not from milestone names. Date of audit: 2026-10-01.

**Status values**

- `done`: implemented and proved by an automated test or script that does not depend on a model.
- `done-fake-only`: implemented; verified only against the fake ComfyUI (`createFakeComfy`) or synthetic media. Live ComfyUI or art judgement is still needed (see "Needs live ComfyUI / user decision").
- `partial`: some of the requirement works; the gap is stated.
- `missing`: not implemented.

**Proof abbreviations.** `core/x` = `packages/core/tests/x.test.ts`; `export/x` = `packages/export/tests/x.test.ts`; `media/x`, `comfy/transport`, `storage/db` likewise; `server` = `apps/server/tests/server.test.ts`; `cli` = `apps/cli/tests/cli.test.ts`. `recovery-smoke:<scenario>` = `bun scripts/recovery-smoke.ts --scenario <scenario>` (fake ComfyUI, child server, SIGKILL/restart; not re-run in this audit). `godot-verify` = `bun packages/export/scripts/godot-verify.ts`; `godot-verify-sprites` = `bun packages/export/scripts/godot-verify-sprites.ts` (both re-run in this audit against Godot 4.7.2, all checks passed). `audit` = `bun run audit` (`scripts/audit-operations.ts`). `UI` = `apps/web/src/features/...`.

## Known limitations

- **Local trust model (user amendment 2).** No credentials. Identity comes from the transport: an allowed browser `Origin` is the human UI; no `Origin` is an agent. A hostile local process that forges an `Origin` header is treated as the human. The design guards against accidents and cross-site requests only.
- **Workflow catalogue** (`workflow.list/inspect/preflight`) is not browsable in the UI on its own.
- **Atomic export** requires a same-filesystem relative directory symlink and was tested on macOS (APFS) only.
- **Running ComfyUI jobs cannot be cancelled** (`CANCEL_UNAVAILABLE`); only queued prompts are deleted by id. There is no global interrupt by design.
- **`feasibility.ts`** hard-codes Cortex trial constants (guide scale, feet position, prompts) and is a bounded art-proof tool, not a general command; its `cleanup-export` and `cleanup-import` actions are not implemented because `candidate.export-cleanup/import-cleanup` supersede them.
- **`project.completeness` cost** grows with assets x branches (one `computeSteps` per asset and branch plus three review-queue scans per call).
- **Web bundle** is one 955 kB chunk (280 kB gzip); no code splitting.
- **No frontend automated tests** (by plan); UI behaviour is verified by exercising the built SPA.
- **Duplicate aborted queries.** On a deep-link load the browser reports paired `net::ERR_ABORTED` POSTs (`project.inspect`, `asset.list`, `export.list`, `project.recent`); they are cancelled duplicates of queries re-keyed once the selected project resolves. No console errors result; not investigated further.
- **Tool limitation seen in the audit:** the Chrome for Testing helper timed out on `tab.goto` navigations while the app kept an SSE stream open; routes were exercised by `pushState` and by opening tabs directly.
- **Audit script test check** is a name-substring match over tests and scripts; it flags a missing reference, not missing coverage of branches.
- **Recovery smoke** covers five scenarios (`collection-restart`, `partial-download`, `processing-restart`, `promotion-failure`, `export-failure`) with the fake ComfyUI; it was not re-run in this audit.
- **Poor tile from `krea2-variation-opaque`.** The live tile run reproduced the reference's content instead of producing a new tile. This is a recipe/prompt-fit limitation of the identity-edit path for tiles, not a verified Brainforge defect; no tile workflow is accepted.
- **Art issues seen live:** `key-disabled` and golden tint artifacts in generated art; a thin light fringe around the figure in processed contact sheets.
- **Construction sheet views:** the front and profile regions both came back three-quarter (only the rear was a true rear). The skill does not warn agents about this.
- **Scale-anchor provenance:** the scale-anchor fix was verified live (processed standing height 217 px at `subjectHeightPx` 216 and 181 at 180; max alpha 255 after `snap-near-opaque`). The anchor measures the approved reference's height; it records its source output and hash, but processed height still depends on that reference's measured silhouette, so a differently framed reference changes the result.
- **Video extraction not implemented** (row 93) and the local ffmpeg binary is broken.
- **`wan22-motion-opaque` not run live.**
- **Pixel-art run:** four bugs were found and fixed during the live UI/icon project; the fixes are not itemised in this ledger.
- **No real omp session** was used; the "external agent" was a CLI-driving agent. Step 11's second generated walk was a fps change.
