# Brainforge web workbench

Mode: Operate. Scope: all apps/web routes. Audience: solo indie 2D game developer on a macOS desktop. Approved brief: docs/WEB-UI-REDESIGN.md. Equal priorities: visible next actions, precise artwork judgment, uninterrupted production context. Preserve existing capabilities and human gates.

## Direction contract

**THESIS:** Animation Checking Room: hold the artwork still while the surrounding tools change. Reject the old eight-page administrative sidebar and repeated full-width pipeline panels.

**OWN-WORLD:** Neutral graphite and slate, clear near-white text, restrained cool-blue selection/action accents; intentional light counterpart. System sans, compact hierarchy, fine separators, squared-off soft corners, flat panes rather than nested cards. Original output colors stay untouched.

**STORY:** Workbench shows what remains; selecting an asset carries its branch and task into production and review. Releases separates promotion, activation, and export. Activity records work; settings stay utilities.

**FIRST VIEWPORT:** Compact top header and four-destination navigation, narrow searchable asset/task navigator, dominant artwork stage, contextual decision inspector, candidate or frame strip below. At 1440×757 show output, playback, exact identity, and next decision together.

**FORM:** User chose Animation Checking Room, the grounded pick, over Exposure Sheet and catalog challengers. Seed e2b48247. Code-led: no generated comp. Preserve existing viewers and operation contracts; build the real task topology, not a theme overlay.

**SIGNATURE:** Retain the asset, change the task. Selection and Back preserve branch/output/queue context. Live updates never move the action under the pointer. Fast state-only transitions, reduced-motion support, light/dark/checker viewing independent of theme.

Proof: actual registered image/animation outputs, authoritative readiness, immutable versions, explicit gate decisions, export plans. No fabricated metrics, costs, or capability claims. No new pipeline, GPU spend, or live-project mutation for verification. Desktop widths and zoom adapt through collapsible navigation and accessible contextual inspectors.
